Newton's Method calculator

GameRecs

A personalized game recommendation web application that generates recommendations based on users' game ratings and preferences. Built with Spring Boot, HTML/CSS, and vanilla JS.

Users rate games they have played to add them to their personal game catalogue. Features of each game receive a score, which accumulates as a user adds more games with those features. Top features are used to define the recommendation candidate pool from IGDB (which supplies all game metadata), and a random subset of this pool is chosen for each recommendation batch. Recommendations are then scored and ranked based on the sum of the scores of their features.

When a user views a recommended game, it accumulates recommendation pressure once per batch generation. This pressure is subtracted from its score the next time it is recommended and decays over time, encouraging fresh recommendations without permanently suppressing relevant games.
